# Life OS

Персональная операционная система жизни в тёмной теме «Гримуар» (есть светлая «Пергамент»): реалистичный план дня вокруг работы 07:00-18:00, снижение веса, сон и восстановление, обучение с интервальным повторением, привычки без наказаний, полноценный отдых, аналитика и ассистент, который работает с реальными данными.

Одно приложение (PWA) работает на Windows, iPhone и iPad, хранит данные локально и без интернета, синхронизируется через твою собственную базу Supabase. Данные Apple Health и Apple Watch приходят автоматически через официальное приложение Apple «Команды».

---

## 1. Архитектура и честные ограничения

```
 Apple Watch ──(запись в Health)──┐
                                  ▼
 iPhone: Apple Health ──► «Команды» (автоматизация по расписанию) ──HTTPS──┐
 Apple Watch: «Команды» (вода, привычка, вес, заметка, голосом через Siri) ─┤
                                                                            ▼
                                             Supabase (Postgres + Auth + RLS)
                                             items · health_samples · ingest_tokens
                                                                            ▲
 Windows (Edge/Chrome, установленное PWA) ◄──── синхронизация ────► iPhone / iPad (PWA)
          IndexedDB офлайн                                              IndexedDB офлайн
```

| Компонент | Решение | Почему |
|---|---|---|
| Клиент | PWA на чистом JavaScript (ES-модули), без сборки и зависимостей | Один код для Windows, iPhone, iPad. Устанавливается как приложение, работает офлайн, обновляется без App Store |
| Локальное хранилище | IndexedDB, все данные на устройстве | Работа без интернета, мгновенный отклик |
| Сервер и база | Supabase: Postgres, Auth (email + пароль), Row Level Security | Бесплатный тариф, работает 24/7, ноутбук может быть выключен |
| Синхронизация | Offline-first: изменения помечаются и отправляются пакетами; с сервера забираются изменения по серверному курсору; конфликты по принципу «побеждает более позднее изменение» | Надёжно при плохой связи, нет потерь при офлайне |
| Apple Health | Быстрая команда iOS «Найти образцы здоровья» → HTTPS → функция `ingest_health` | Веб-приложение не имеет доступа к HealthKit. Без Mac и Xcode это единственный официальный способ |
| Apple Watch | Быстрые команды на часах → функция `quick_log`; тренировки и сон часы пишут в Health сами | Нативное приложение watchOS собирается только в Xcode на Mac |
| Ассистент | Правила и статистика на устройстве (работают офлайн) + по желанию диалог с Claude по своему API-ключу | Выводы опираются на данные, а не на общие советы |

**Что ограничено и чем заменено:**

- **HealthKit напрямую.** Нужен нативный iOS-модуль на Swift, а его сборка требует Mac с Xcode (и для стабильной установки подписку Apple Developer, $99 в год: без неё приложение надо переустанавливать каждые 7 дней). Сейчас мостом служат «Команды». Схема базы уже готова для нативного модуля: если появится Mac, модуль будет писать в ту же таблицу `health_samples`.
- **Фоновое обновление.** Автоматизация «Команд» запускается по расписанию без открытия приложения. Ограничение Apple: пока iPhone заблокирован, данные Health зашифрованы, и запуск в этот момент может вернуть пустой результат. Поэтому команда каждый раз забирает последние 3 дня, а сервер отбрасывает дубликаты: пропущенный запуск догоняется следующим.
- **Приложение на часах.** Вместо собственного приложения watchOS используются быстрые команды (запуск с циферблата и через Siri) и штатные «Таймер» и «Тренировка».
- **Apple Calendar, Reminders, Windows Calendar.** Прямой записи из веб-приложения нет. План любого дня экспортируется в `.ics` (открывается в Apple Calendar и Outlook), есть готовый календарь напоминаний (отбой, взвешивание, недельный обзор) с уведомлениями на iPhone и часах.
- **Push-уведомления.** Для PWA на iOS нужен отдельный push-сервер. Напоминания закрыты календарём `.ics` и штатными напоминаниями часов. Таймер учёбы показывает уведомление, пока приложение открыто.

## 2. Установка (≈30 минут один раз)

### Шаг 1. База Supabase (5 минут)

1. Зайди на supabase.com → **Start your project** → войди через GitHub.
2. **New project**: имя `life-os`, пароль базы (сохрани в менеджер паролей), регион **Central EU (Frankfurt)** или ближайший. Тариф Free.
3. Когда проект создастся: **SQL Editor** → **New query** → вставь весь файл `supabase/schema.sql` → **Run**. Должно быть «Success».
4. **Authentication → Sign In / Providers → Email**: для личного использования удобно выключить **Confirm email** (иначе после регистрации нужно подтвердить почту по ссылке).
5. **Project Settings → API** (или **Data API**): скопируй **Project URL** (`https://xxxx.supabase.co`) и **anon public key** (или publishable key). Это публичные значения: доступ к данным всё равно защищён паролем и Row Level Security.

> Бесплатный проект Supabase ставится на паузу после 7 дней без запросов. При ежедневном использовании и автоматизации «Команд» этого не произойдёт; если всё же случилось, проект возобновляется кнопкой в панели.

### Шаг 2. Разместить приложение (5 минут)

PWA должно открываться по HTTPS. Самый простой бесплатный вариант: GitHub Pages.

1. github.com → **New repository** → имя `life-os` → Public → Create.
2. **Add file → Upload files** → перетащи **содержимое** папки `app` (файлы `index.html`, `sw.js`, `manifest.webmanifest` и папки `css`, `js`, `icons`) → **Commit**.
3. **Settings → Pages → Source: Deploy from a branch**, ветка `main`, папка `/ (root)` → Save.
4. Через 1-2 минуты приложение доступно по адресу `https://<твой-логин>.github.io/life-os/`.

В репозитории только код. Твои данные хранятся на устройствах и в Supabase, не в GitHub.

Альтернативы: Cloudflare Pages или Netlify (перетащить папку `app` в окно загрузки).

### Шаг 3. Устройства

**Windows.** Открой адрес в Edge или Chrome → значок «Установить приложение» в адресной строке. Life OS появится в меню «Пуск» и на панели задач, работает в отдельном окне и офлайн.

**iPhone и iPad.** Открой адрес в **Safari** → «Поделиться» → **На экран «Домой»**. Запускай с иконки: так приложение работает на весь экран, офлайн и хранит данные надёжнее, чем вкладка браузера.

**Первый вход на каждом устройстве.** Настройки → Синхронизация → вставь Project URL и anon key → на первом устройстве «Создать аккаунт», на остальных «Войти» с тем же email и паролем.

### Шаг 4. Apple Health → Life OS (15 минут)

1. В приложении: Настройки → **Apple Health и Watch** → **Создать ключ**. Скопируй ключ, адрес `ingest_health` и anon key (там есть кнопки «Копировать»).
2. На iPhone откройте «Команды» → **+** → назови `Life OS Health`. Для каждого показателя добавь блок из 4 действий:
   1. **Найти образцы здоровья**: тип (таблица ниже), фильтр «Дата начала» за последние **3 дня** (для первого запуска поставь **90 дней**, чтобы загрузить историю, потом верни 3), «Группировать по» как в таблице.
   2. **Повторить с каждым**. Внутри действие **Текст**: `Значение|Дата начала|Дата окончания`, где каждое слово это переменная «Объект повтора» с выбранным свойством. У обеих дат в настройках переменной выбери формат **ISO 8601** и включи время.
   3. После «Конец повтора»: **Объединить текст** → «Результаты повтора», разделитель «Пользовательский» `;`
   4. **Получить содержимое URL**: адрес `.../rest/v1/rpc/ingest_health`, метод **POST**, заголовки `apikey` = anon key и `Content-Type` = `application/json`, тело **JSON**: `p_token` = ключ, `p_type` = код из таблицы, `p_rows` = «Объединённый текст».

   Первый блок собери вручную, остальные получаются через «Дублировать» и смену типа и `p_type`.

| Тип в «Командах» | `p_type` | Группировать по |
|---|---|---|
| Шаги | `steps` | День |
| Расстояние ходьбы и бега | `distance` | День |
| Активная энергия | `active_energy` | День |
| Энергия покоя | `basal_energy` | День |
| Время упражнений | `exercise_min` | День |
| Время стоя | `stand_min` | День |
| Пульс в покое | `resting_hr` | нет |
| Вариабельность пульса | `hrv` | нет |
| Пульс (для средней и максимальной ЧСС) | `heart_rate` | Час |
| Частота дыхания | `resp_rate` | нет |
| Насыщение крови кислородом | `spo2` | нет |
| Температура запястья во сне | `wrist_temp` | нет |
| Вес | `weight` | нет |
| Процент жира | `body_fat` | нет |
| Артериальное давление: систолическое / диастолическое | `bp_sys` / `bp_dia` | нет |
| Анализ сна | `sleep` | нет |

   Для сна «Значение» содержит стадию (основной, глубокий, REM, бодрствование): приложение понимает русские и английские названия. Если в твоей версии iOS в списке типов есть «Тренировки», добавь блок с `p_type` = `workout` и свойством «Тип» вместо «Значения».

3. Запусти команду вручную один раз. iOS попросит разрешения на чтение каждой категории Health: это и есть официальные разрешения HealthKit по категориям, их можно изменить в Настройки → Здоровье → Доступ к данным.
4. **Автоматизация**: «Команды» → «Автоматизация» → **+** → «Время суток»: 07:05, 13:00, 18:45, 22:00, ежедневно, **«Запускать сразу»**, уведомление выключить. Удобно добавить триггер «При открытии приложения» для приложения, которое открываешь каждое утро.

После этого критерий готовности выполняется: надеваешь часы, живёшь обычный день, спишь, утром открываешь Life OS на Windows или iPhone, а сон, пульс покоя, HRV, шаги и активность уже там. Индекс готовности и режим дня пересчитываются сами.

### Шаг 5. Apple Watch (5 минут)

Создай короткие команды и включи в каждой «Показывать на Apple Watch». Все используют адрес `.../rest/v1/rpc/quick_log`, POST, те же заголовки, тело JSON `p_token`, `p_kind`, `p_value`:

| Команда | Действия | `p_kind` / `p_value` |
|---|---|---|
| Life OS Вода | Выбрать из меню: 250, 330, 500 | `water` / мл |
| Life OS Привычка | Список названий привычек → Выбрать из списка | `habit` / название |
| Life OS Вес | Запросить ввод: число | `weight` / кг |
| Life OS Самочувствие | Выбрать из меню 1-5 | `energy` / 1-5 |
| Life OS Заметка | Диктовать текст | `note` / текст |

Запуск: приложение «Команды» на часах, усложнение на циферблате или голосом: «Привет, Siri, Life OS вода». Часам нужен iPhone рядом или Wi-Fi/LTE.

Таймеры учёбы и тренировок на часах: штатные «Таймер» и «Тренировка» (тренировка автоматически попадёт в Health и в Life OS). Напоминания о движении: Активность → «Напоминание встать».

### Шаг 6. Напоминания в календаре (1 минута)

Настройки → Apple Health и Watch → **Календарь напоминаний (.ics)**. Открой файл на iPhone: подготовка ко сну каждый вечер, взвешивание пн/ср/пт, недельный обзор в воскресенье, замер окружностей раз в 2 недели. Уведомления придут на iPhone и часы.

## 3. Первый запуск: всё уже заполнено

При первом открытии приложение само создаёт стартовое содержание, пустых разделов нет:

- **Программа обучения на 13 недель (≈90 дней):** 65 тем по 30-40 минут с чередованием: хирургия (общая, колоректальная, онкология, торакальная), подготовка к USMLE (вместо английского; First Aid 2025 + 20 вопросов QBank на тему), периоперационная медицина и ICU, анатомия и физиология, наука и EBM. У каждой темы цель, 3 вопроса для Active Recall, источник и практическое применение. Пройденная тема автоматически превращается в карточки интервального повторения.
- **Меню на 7 дней** из продуктов, доступных в Казахстане: время, блюда, граммы, ккал и БЖУ, готовка впрок 2 раза в неделю, список покупок, быстрые варианты для рабочего дня. Порции масштабируются под личную цель калорий, белок при снижении калорий сохраняется.
- **Программа тренировок на 12 недель:** A и B (силовые на всё тело), C (кардио в зоне 2 и кор), три фазы с прогрессией, вариант для зала и для дома, цель по шагам растёт на 1000 каждые 2 недели.
- **Стратегия на 7 дней, 30 и 90 дней, 6 и 12 месяцев, 3 года** по уровням «Основа», «Рост», «Исследование» с измеримыми целями, действиями, нагрузкой, критериями и условиями пересмотра. Прогресс по большинству целей считается автоматически.
- **Проекты** (TNT, LLND, AddAll и грант, SurgWeek-2 и др.) с лимитом 3 активных и следующим действием на 5-20 минут. Отмечены «проверь статус», потому что их текущее состояние известно только тебе.
- **Ритуалы:** шаги, отбой вовремя, карточки, взвешивание. **Список отдыха**, **Казна** для денег.
- **7 сценариев дня:** стандартный, интенсивный, низкой энергии, тренировочный, учебный, выходной, восстановления. Сценарий выбирается сам по сну, самочувствию, нагрузке и типу дня.
- **Протокол возвращения:** пропуск одного дня ничего не меняет, 3-6 дней: 3 дня облегчённого плана, 7+ дней: неделя мягкого возвращения. Долги не копятся.

### Анкета в профиле

Всё, что приложение не может узнать само, собрано в одной анкете: Профиль → Анкета. Заполни один раз и нажми «Сохранить»: калории, меню, тренировки, расписание и стратегия пересчитаются. Обязательных полей 11 (рост, вес, возраст, ограничения для нагрузок, место тренировок, режим дня), остальное по желанию: исключения в питании, дата экзамена USMLE, деньги, данные синхронизации. Пока анкета не заполнена, значения помечены как предварительные.

## 4. Как устроено приложение

Пять экранов, без вкладок внутри:

- **Сегодня:** что делать сейчас и дальше, план дня, главные задачи, ритуалы одним касанием.
- **Тело:** вес, еда сегодня со следующим приёмом по меню, тренировка по очереди, сон и движение.
- **Знания:** тема дня с вопросами для самопроверки, повторение карточек, прогресс недели.
- **Дела:** задачи, три проекта в работе со следующим шагом, цели на 90 дней.
- **Я:** профиль и анкета, а также всё остальное списком: ритуалы, привал, казна, наставник, летопись, настройки.

Подробности (меню на неделю, вся программа, стратегия, графики) открываются кнопками внизу экранов. Иллюстрации сгенерированы локально в ComfyUI (Animagine XL 4.0) и лежат в `app/art`.

### Запуск на компьютере без хостинга

Двойной клик по `Открыть Life OS.bat`: он запускает маленький локальный сервер и открывает приложение в браузере (нужен Python или Node.js). Для iPhone и iPad всё равно нужен хостинг (шаг 2 установки).

## 5. Как пользоваться

**Утро (1 минута).** Открой «Сегодня»: индекс готовности по сну, HRV, пульсу покоя и самочувствию выбирает режим дня: **Optimal**, **Normal** или **Minimum Viable Day**. Отметь самочувствие 1-5. Режим можно сменить вручную.

**Вечер.** План строится от фактического конца работы: переключение, ужин, одно главное дело (тренировка или учебный блок), обязательные задачи, быт, гарантированный отдых, подготовка ко сну. Если работа закончилась позже, нажми «Работа закончилась позже»: вечер пересоберётся, первой уходит учёба, отдых остаётся. Блоки отмечаются галочкой, у учебных и тренировочных есть таймер.

**Дежурства.** План → Неделя → «Отметить дежурства»: день дежурства и день после него планируются отдельно (восстановительный сон, только одно главное дело), привычки в эти дни не считаются пропущенными.

**Быстрый ввод** (кнопка «+» или Ctrl+K): `вода 300`, `вес 92,4`, `сон 23:30-06:10`, `учёба 30 хирургия`, `тренировка 40 силовая`, `отдых 60 фильм`, `гречка с курицей 520 ккал б40 ж12 у55`, `энергия 4`, `Позвонить в банк завтра !` (`!` обязательная задача, `?` дополнительная).

**Неделя (10 минут, воскресенье).** Ассистент → недельная таблица и выводы. Отметь дежурства на следующую неделю, поставь 1-3 учебные цели недели.

### Принципы, заложенные в систему

- После 11-часового рабочего дня вечером помещается **одно** главное дело. Учёба 3 часа в неделю по умолчанию: это реалистично при работе 07-18 и сохраняет отдых. Если цели не помещаются в неделю, ассистент показывает конфликт с конкретными цифрами.
- Пропуски не превращаются в долг: тренировки и учёба пересчитываются на оставшиеся дни, двойной нагрузки не будет.
- Привычки: процент за 4 недели важнее серии, минимальная версия засчитывается, правило «не пропускать дважды», причины пропусков анализируются, через 3 стабильные недели предлагается усложнение.
- Вес: решения только по сглаженному тренду; темп 0,5-1% массы в неделю; дефицит не больше 25% расхода и не ниже 1500 ккал; расход уточняется по Apple Watch и по фактическому питанию.
- Здоровье: никаких выводов по единичным измерениям. Сигналы появляются только при устойчивых изменениях относительно твоей базы за 4 недели и подписаны как расчётные.

## 6. Данные и резервные копии

- Настройки → Данные → **Скачать JSON**: полная копия (все записи и данные Health). Импорт объединяет записи, режим «заменить всё» восстанавливает состояние полностью.
- **Сводка по дням (CSV)**: сон, шаги, пульс покоя, HRV, вес и тренд, калории, учёба, тренировки, выполнение плана для Excel.
- Копия всегда есть и в Supabase (Dashboard → Table Editor). Раз в месяц полезно скачивать JSON в iCloud Drive или OneDrive.

## 7. Безопасность

- Row Level Security: каждая строка доступна только владельцу аккаунта.
- Ключ быстрых команд хранится в базе только в виде SHA-256 хеша; новый ключ отзывает старый; через ключ можно только добавлять измерения и быстрые записи, читать данные нельзя.
- API-ключ Claude хранится только на устройстве и не синхронизируется. В запрос уходит агрегированная сводка за 28 дней без заметок.
